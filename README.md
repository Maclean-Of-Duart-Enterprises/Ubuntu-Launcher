# Ubuntu Launcher

**Ubuntu Launcher** is an open-source Android HOME launcher that brings an Ubuntu-inspired phone and desktop experience to Android.

The launcher automatically adapts its interface to device orientation: portrait mode provides a mobile-focused Ubuntu-style launcher, while landscape mode transforms into a desktop-style environment with a side dock, application grid, search, and desktop-oriented navigation.

## Features

- Full Android HOME/default-launcher support
- Ubuntu-inspired interface and visual design
- Automatic portrait and landscape layouts
- Desktop-style interface in landscape orientation
- Installed application discovery and launching
- Application search
- Searchable Android system settings
- Pinnable application dock
- Long-press apps to pin or unpin them
- Landscape desktop side dock
- Dumb Phone Mode
- Select exactly which apps are available in Dumb Phone Mode
- Hidden Apps system
- Hidden apps removed from the launcher home, drawer, search, and Dumb Phone Mode
- Hidden apps accessible through Launcher Settings
- Wi-Fi settings shortcut
- Bluetooth settings shortcut
- Display and rotation settings
- Sound settings
- Storage settings
- Security settings
- Accessibility settings
- Full Android system settings shortcut
- Automatic app-list refresh when applications are installed, removed, or updated
- Touch-friendly Android interface
- Phone and larger-screen orientation support

## Dumb Phone Mode

Dumb Phone Mode provides a simplified launcher environment while allowing the user to choose which installed applications remain accessible.

## Hidden Applications

Applications can be hidden from the normal launcher interface and managed from **Ubuntu Launcher Settings → Hidden applications**.

This is a launcher-level hiding feature. It does not uninstall, disable, encrypt, or system-lock applications.
